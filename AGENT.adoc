== Projet

**Nom** : workspace-agent — Cockpit Agentique IntelliJ (N-IDE)
**Stack** : Kotlin, IntelliJ Platform Plugin SDK, Gradle, koog+langchain4j, PSI, RAG
**GroupId** : education.cccp.intellij
**Licence** : Apache 2.0
**Document de vision** : COCKPIT_VISION.adoc (racine workspace)

=== Objectif

Plugin JetBrains Platform pour le poste de pilotage du développement assisté par IA.

*Portée actée (décision pilote 2026-09-17)* : le plugin *pilote ET observe*.
- *Observer* — dashboards, visualisation de l'output, arbre des sessions,
  inspection des structures de données (graphes, plans, backlogs, sorties de tâches).
- *Piloter* — lancer des tâches Gradle (Tooling API), ouvrir/fermer des sessions,
  manipuler visuellement les structures. Le plugin *propose*, l'humain *valide*.

5 dashboards :
- Conso tokens
- Knowledge Graph (SQL + graphify)
- Historique sessions opencode
- RAG Context
- Chain Monitor koog

Actions IA menu contextuel : Generate, Explain, Document, Refactor Suggest, Fix Error.

== Règles Absolues

=== Git

Commit/push/merge **autorisés** (décision pilote 2026-09-17 — suppression de
l'interdiction formelle).

Lecture seule toujours autorisée : `git status`, `git diff`, `git log`, `git show`

*Seule limite* : ne JAMAIS commiter de secret.

=== Tests

L'agent NE DOIT JAMAIS lancer de tests en fin de session SANS permission explicite.

=== Secrets

* Jamais de secrets en dur dans le code
* Jamais de credentials dans les fichiers de config
* Jamais de tokens API commités dans Git

=== Fichiers de configuration

* Backup obligatoire avant modification d'un fichier non versionné
* Privilégier `Edit` (partiel) plutôt que `Write` (écrasement)

=== Méthodologie

* **TDD/BDD/DDD en baby steps** — test unitaire → fonctionnel → Cucumber
* **Clean Architecture + Clean Code** — pas de shortcuts
* **Parallélisation autorisée** — @xp, subagents et sessions concurrentes sont
  des outils légitimes (décision pilote 2026-09-17 — la règle « SÉQUENTIEL PUR »
  est supprimée de l'écosystème)
* **1 fichier à la fois** — modifier, compiler, tester, puis passer au suivant
  (discipline de travail recommandée, non une interdiction de paralléliser)

== Statut du Borough — PARKÉ (décision pilote 2026-09-17)

*Le chantier cockpit IntelliJ est ABANDONNÉ avant le premier incrément.*
Motif : trop de travail pour peu de bénéfice. La vision v1 (79 pts) divergeait
du besoin réel (plan de contrôle du workspace) et aucun code n'a été produit
en 4 mois. Détail : `.agents/sessions/001-abandon-cockpit-intellij.adoc`.

*Conséquence pratique* : ne PAS rouvrir ce chantier sans demande explicite du
pilote. Le besoin multi-sessions, s'il revient, se recadre ex nihilo à partir
du besoin (registre de sessions + read model unifié), jamais à partir des
EPICs ci-dessous. Les documents existants sont conservés pour traçabilité.
